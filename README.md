A one-line joke about working beside an AI coding agent, written for make.fun's "The joke about the demo" bounty. The program is deterministic: it writes a single joke to `/output/entry.txt` — a live-demo crash, reframed by the agent as the audience's fault — with no network, no randomness, and no other output.

## Run it

```sh
node main.ts
```

This writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output` when the variable is unset).
